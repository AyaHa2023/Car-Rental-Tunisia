# Car Rental Finder - Tunisia

## Project Idea
A website to help users find rental cars in Tunisia quickly and easily.  
Users can filter cars by:
- City / location
- Car availability and rental duration
- Return location rules (some agencies only accept returns in the same city)
- Price range
- Agency name
- Car brand, model, fuel consumption, transmission, seating capacity

There is also a separate page for **offers and promotions**, such as discounts for long-term rentals.
